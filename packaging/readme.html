安装内容

  • /Library/Audio/Plug-Ins/HAL/HuishengStudio.driver — 八台单向虚拟设备（输出四台、输入四台）
  • /Library/Audio/Plug-Ins/VST3/HsAudio Capture.vst3 — 采集
  • /Library/Audio/Plug-Ins/VST3/HsAudio Return.vst3 — 回传
  • /Library/Audio/Plug-Ins/Components/HsAudio Capture.component 与 HsAudio Return.component — 同样两个插件，给 Logic / GarageBand 用
  • /Applications/HuishengStudio Agent.app — 后台服务

装完之后

  1. 系统设置 → 声音：输出页应能看到 HsAudioSC 1/2 … 7/8，输入页应能看到 HsAudioSR 1/2 … 7/8。编号相同的一对是一条环回（DAW 往 SC n/n 送， OBS 从 SR n/n 取）。
  2. 看不到就重启一次电脑；还是看不到，在终端执行 sudo killall coreaudiod，让系统重新扫描音频驱动。
  3. 在 Studio One 里插上 HsAudio Capture，第一次选择软件时会请求 「屏幕与系统音频录制」权限（仅 macOS 14.2+；更早的系统上软件选择按钮是灰的， 请改用虚拟通道）。
  4. 要同时采好几个软件：可以在同一个插件里勾选多个软件（它们相加后一起送进这条轨道）， 也可以在不同轨道上各插一个 HsAudio Capture 分别选一个软件，互不影响，关掉其中一个 不影响其他几个（最多八个插件，每个最多八个软件）。App 的采样率和工程不一致 （比如 44.1 kHz 的软件配 48 kHz 的工程）会自动重采样，不需要手动对齐。

卸载

删掉下面这些，然后在终端执行 sudo killall coreaudiod：

  • /Library/Audio/Plug-Ins/HAL/HuishengStudio.driver
  • /Library/Audio/Plug-Ins/VST3/HsAudio Capture.vst3 与 HsAudio Return.vst3
  • /Library/Audio/Plug-Ins/Components/HsAudio Capture.component 与 HsAudio Return.component
  • 如果装过 1.0.7，旧名字的两个插件（HuishengStudio Capture/Return） 也会一并删掉
  • /Applications/HuishengStudio Agent.app
